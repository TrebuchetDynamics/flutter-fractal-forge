# MilkDrop/Carpathian recursive-object study

## Decision summary

Fractal Forge should transfer only the reference clip’s broad scene grammar: a single floating mathematical object, slow rotation, recursive density, generated complementary color, an emissive edge, and dominant black space. It should not reproduce MilkDrop’s defining texture-feedback/audio pipeline or any preset-specific form.

The implementation adds five stable 3D identities to the existing ray-marched catalog:

1. **Ternary Cayley Lumen** — a threefold graph-directed capsule tree represented by azimuthal symmetry folding.
2. **Gyroid Echo Reliquary** — recursively finer analytic gyroid membranes clipped to an orb.
3. **Möbius Echo Nest** — nested similarity copies of a one-sided half-twist ribbon.
4. **Fibonacci Cone Bloom** — a twelve-map spherical-Fibonacci IFS with tapered terminal buds.
5. **Chebyshev Nodal Lantern** — clipped nodal sheets generated by Chebyshev recurrence and frequency doubling.

These are catalog identities because their transform grammar, topology, or recurrence differs. Camera, palette, halo, parameter values, and animation phase are presentation and do not create extra identities.

### Repeated visual traits

- Near-black negative space dominates each frame.
- One centered object usually occupies approximately one-third to one-half of the frame height.
- Silhouettes vary among rounded clusters, panels, folded volumes, shells, crystals, and carpet-like blocks.
- Motion is principally slow orientation drift and object replacement/transition.
- Detail is legible at two scales: a strong silhouette and dense interior/surface relief.
- Violet, blue, green, cyan, magenta, and gold commonly appear as complementary emissive accents.
- Halos remain local to the object rather than filling the frame.

These observations define measurable acceptance criteria but do not authorize copying any particular frame or preset.

## Why this is not a MilkDrop integration

MilkDrop’s documented architecture evaluates per-frame and warp-mesh equations, warps a previous frame through feedback textures, draws audio-reactive overlays, composites the result, and swaps ping-pong buffers. MilkDrop3 also supports preset compatibility, beat-triggered behavior, sprites, transition masks, and audio-analysis helpers.

The new Fractal Forge shader instead:

- has no sampler uniform;
- has no previous-frame feedback;
- has no FFT, waveform, beat, sprite, texture, or external media input;
- uses only analytic distance bounds, finite deterministic loops, generated palettes, and object-space rotation;
- computes its halo from bounded near-miss accumulation on the primary ray;
- remains offline and deterministic for identical uniform inputs.

## Licensing boundary

## Shader and catalog architecture

All five modules use one coherent runtime-effect asset, `carpathian_recursive_objects_gpu.frag`, and the established 16-float ray-marched 3D uniform contract. `uFractalType` is fixed by each declarative config and is not exposed as a variant control, so the five modules cannot be converted into one another from the UI.

The shared public controls remain honest:

- **Power** is relabeled per identity as branch scale, base frequency, echo scale, child scale, or polynomial order.
- **Iterations** controls finite recursive depth and is capped to the effective loop ceiling for each construction.
- **Steps** controls the full 20–200 primary-march loop range.
- **Bailout** controls march reach and halo response.
- **Color scheme**, camera rotation, pan, and zoom remain presentation controls.

The shader first intersects a tight bounding sphere, conservatively marches only the enclosed interval, evaluates a tetrahedral normal only after a hit, accumulates bounded near-miss emission, and produces clear premultiplied misses in transparent mode.

## Construction notes

### Ternary Cayley Lumen

A capsule is evaluated at every recursive generation. Translating to the parent tip, folding azimuth into a 120-degree fundamental sector, aligning the radial/y plane with a fixed branch angle, and applying the inverse contraction represents all three children without enumerating `3^n` capsules. The scale-corrected minimum over generations preserves trunk and descendants.

### Gyroid Echo Reliquary

The standard field

`g(x,y,z) = sin(x)cos(y) + sin(y)cos(z) + sin(z)cos(x)`

is evaluated at up to four rotated/scaled levels. Each level contributes a thick zero-set membrane divided by a conservative gradient bound. The union is intersected with a sphere, yielding a bounded porous object rather than an infinite periodic field.

### Möbius Echo Nest

For polar angle `theta`, radial and vertical offsets are rotated by `theta/2`, creating the characteristic frame reversal after one circuit. A rounded rectangular cross-section gives the solid ribbon. Irrationally related rotations and geometric scale produce nested copies while retaining the one-sided identity.

### Fibonacci Cone Bloom

Twelve contraction maps are arranged on spherical-Fibonacci directions using the golden angle. At each depth, the finite distance estimator evaluates the oriented capped-cone distance in all twelve child frames, follows the minimizing branch, and retains the minimum encountered generation. This graph-directed approximation creates tapered buds rather than claiming an exact enumeration of all `12^depth` descendants.

### Chebyshev Nodal Lantern

The recurrence `T(n+1)=2xT(n)-T(n-1)` generates bounded orthogonal-polynomial fields. Cyclic products form nodal sheets, while level-to-level frequency doubling creates finer descendants. Fractional base order blends neighboring Chebyshev polynomials so every exposed 0.1 parameter step is active.

## Acceptance criteria

Automated tests must establish:

1. five unique fixed identities, all 3D and time-driven;
2. exact shared asset registration and no exposed identity selector;
3. runtime compilation and structured non-full-frame defaults;
4. pairwise visual separation;
5. visible advancement after one production-clock second;
6. endpoint responsiveness for power, recursion depth, step budget, bailout, palette, and rotation;
7. clear premultiplied transparent misses;
8. source/provenance package presence and asset-import prohibition;
9. clean analyzer, full Flutter suite, and release Web build.

Physical-device frame-time profiling remains a release gate; desktop test rendering is useful but is not authoritative mobile performance evidence.

## Weakest evidence gap

The exact Reddit preset(s) and their authored equations were deliberately not identified or inspected, and the scholarly search did not yield one source covering the combined aesthetic, real-time feedback visualizers, and all five selected mathematical constructions. The design translation is therefore explicitly original and implementation-led, with mathematical and renderer sources serving as separate contextual leads.
