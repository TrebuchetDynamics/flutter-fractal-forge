## Formula and independent reference

Let `C(x,y,z)=(y,z,x)`. The base distortion is

`F(p) = p + sin(C(p))`, with vector sine componentwise.

Evaluate all new coordinates from the same old vector. In-place x/y/z assignment changes the map. Repeated unscaled `F` gives organic deformation; the finer-scale construction uses shrinking displacement and increasing spatial frequency. The decided finite implementation is

`q_0 = p`

`q_(n+1) = q_n + a * 2^(-n) * sin(2^n * C(q_n) + phi)` for `n=0..N-1`.

`g(p) = length(q_N) - R`, and the surface is `g(p)=0`.

The sphere level set is unchanged if written as squared length minus squared radius; the length form is selected for bounded field stepping. `a=1`, `phi=0` recovers the displayed cyclic base map at the first scale. Strength, sphere radius, finite-depth cap and app presets below are implementation choices, not author-approved settings.

Independent Python double evaluation, not app/shader execution: for `p=(0, pi/2, 0)`, `a=1`, `phi=0`, the first step is `(1, 1.5707963267948966, 0)` and the second scaled step is `(1, 1.5707963267948966, 0.45464871341284085)`. These fixtures distinguish simultaneous cyclic updates and scaled composition. Require independent test fixtures, not expectations generated by the implementation under test.

## Rendering contract and numerical limits

The warped field is **not a signed-distance function**. Raw `abs(g)` steps can skip thin folds. For this map, the cyclic permutation is orthogonal and each warp Jacobian has operator norm at most `1+abs(a)`: the scale factors cancel in its derivative. Therefore `L=(1+abs(a))^N` is a conservative global Lipschitz bound for `g`. Use a conservative `abs(g)/L` step plus bounded convergence/refinement; do not copy a Mandelbulb distance estimator or certify a hit merely because a conservative lower-bound step becomes small. Verify a residual/bracket-based hit criterion, central-difference normals, finite rays and non-convergence behavior explicitly.

Every surface point lies within `R + sqrt(3)*abs(a)*sum(2^(-n), n=0..N-1)` of the origin. Use that finite enclosure for ray entry/exit and camera framing. The bound concerns the specified finite composition, not an infinite fractal proof. For `a=1`, `N=6`, `R=1`, the computed bound is `4.409975027401227`, and `L=64`.

Planner-selected first release: one sphere only; finite depth `0..6` (default 3), strength `0..1` (default 0.8), radius `0.25..2` (default 1), phase in radians (default 0), existing palette/camera/transparent PNG support and bounded ray-step control (default 256, hard maximum 512). Animation is opt-in using existing module animation contracts; persisted phase and export time must reproduce the same geometry. Depth 0 or strength 0 must render the corresponding ordinary sphere. Later implicit shapes, arbitrary distortion languages and a general warp framework are out of scope.

High depth increases both field cost and conservative-marching difficulty; a hard cap is not an FPS guarantee. Measure default/max settings on a named backend, disclose missed/non-convergent rays, and tune default camera/quality only from actual captures. Never silently lower the requested depth, treat an unconverged ray as a valid surface, or claim CPU fallback if unsupported. Use existing renderer capability/failure reporting.
